<h1>PROJETO AEP 6° SEMESTRE - ENGENHARIA DE SOFTWARE</h1>
Projeto voltado para a AEP do 6° Semestre do curso de Engenharia de Software.

<h1>ODS ESCOLHIDA</h1>
Para este projeto, após uma análise dos Objetivos de Desenvolvimento Sustentável (ODS) da ONU, optamos pela ODS 11: Cidades e Comunidades Sustentáveis, que tem como objetivo tornar as cidades e comunidades mais inclusivas, seguras, resilientes e sustentáveis.

<h1>O PROBLEMA</h1>
Com este projeto buscamos resolver um problema muito presente nas pequenas e grandes cidades da modernidade: irregularidades na infraestrutura urbana. Para auxiliar na resolução dessa questão, iremos desenvolver uma aplicação de chamados para que a população consiga comunicar eventuais problemas infraestruturais urbanos em sua região às autoridades competentes. 

<h1>TECNOLOGIAS UTILIZADAS</h1>
Para este projeto será utilizada as seguintes ferramentas e tecnologias:
<ul>
  <li>Linguagem de programação Java</li>
  <li>Framework Spring boot</li>
  <li>Banco de dados noSQL MongoDB</li>
  <li>JUnit e Mockito para testes</li>
</ul>
